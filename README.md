# Hvad spørger Per om til eksamen?

## Spørgsmål til Wordpress og WooCommerce

Jeg udviklede dette script for at variere mine eksamensspørgsmål. Hvis du ved, hvad jeg kan finde på at spørge om - så kan du forberede dine svar. Noget møder du i undervisningen - andet må du selv finde ud af - for nogen spørgsmål fletter WordPress og WooCommerce sammen med tværfaglige emner inden for multimediedesign.

* Vis *hvad* du bruger til xyz. (kan anvende)
* Demonstrer *hvordan* xyz er implementeret, både i *koden* og hvordan *det ser ud* på en skærm. (kan anvende)
* Forklar *hvorfor* du bruger xyz? (reflekterer)
* Begrund med henvisning til konkrete *brugertests*. (data, research)
* Vis, hvordan du *bruger* UX- eller designprincipper, som: Jacob's Law, Fitt's Law, gestaltpsykologi: CRAP, etc. etc. (perspektiverer)
* Kunne opgaven være løst på anden vis? (alternativer)
* Konklusion: *hvad* har du fået ud af at arebjde med xyz?
